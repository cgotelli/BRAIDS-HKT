# Windows alpha 80: coupled stage-outlet treatment

The scoped local-equilibrium MPM correction is described in the
[outlet audit and figures](../validation/sediment/synthetic_expansion/reports/outlet_characteristic_final_v1/AUDIT.md).
It retains conservative sediment export and physical stage reflection without
flattening the bed or changing sediment supply. Resolution-dependent residuals
and failed coarser controls are explicitly retained.

Package: `dist/windows-x86_64/BRAIDS-0.1.0-alpha.80-QGIS-windows-x86_64.zip`.
Native SHA256: `fe07378e29e744f01a21e5f8496dd7de067e53e3f09ae3f79385e68a7e1e9f5a`.

The [installation record](../validation/sediment/synthetic_expansion/reports/outlet_characteristic_final_v1/installation.json)
records verified installed files and the recoverable previous-plugin backup.
No Delft3D source or raw simulation runs are included. Restart QGIS and prepare
a new run; existing prepared runtimes and outputs are unchanged.

This release does not certify the expansion or an experimental braided river.
